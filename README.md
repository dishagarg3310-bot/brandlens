# BrandLens

Pre-publication brand governance platform built for CodeStar 3.0 (Round 2).

Reviews content against approved brand guidelines and facts, explains every finding with a cited source, suggests fixes, and routes drafts through human approval.

## Status
Work in progress. Built during the official Round 2 window (26-28 Oct 2026).
